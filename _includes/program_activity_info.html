{% comment %} Define, para uma atividade da programação, `subtitulo`, `link` (página de detalhes; atividades gerais com `page` apontam para ela) e `link_externo` (true para sites de fora). Parâmetro: activity. Requer `pagina_minicursos` (página /program/tutorials/) para o título dos minicursos. Minicursos: título vindo da página de minicursos no primeiro bloco; nos demais, só "(cont.)" quando houver.
